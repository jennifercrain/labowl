LAB OWL

Concept Gaps

Help students identify what’s unclear and find the right support.

Recognize the Concept Gap

Sometimes a student is stuck because they do not fully understand an underlying concept the code relies on. The code may look confusing because they’re missing a foundational piece of how it works.

Course resources can be hard to search or reference in the middle of a lab. Even then, your role is to support the student’s thinking process. Peer Navigators do not teach or tutor course content or provide direct answers. Help the student identify the gap, reconnect with course resources, and prepare a clear question for the Course Instructor if needed.

A Simple Coaching Check

Before you decide how to proceed, ask yourself whether the student is stuck on the debugging process or the underlying concept.

A Process Problem Sounds Like

  • “My code runs but the output is wrong.”
  • “I keep getting an error and I don’t know how to interpret it.”
  • “I’ve tried a few things but I can’t tell what changed.”

Use Lab Owl to guide debugging.

A Concept Problem Sounds Like

  • “I don’t understand what this code is doing.”
  • “I don’t know what this function means.”
  • “I’ve never really understood loops, lists, or conditionals.”

Use the redirecting steps below.

Guide the Student Through a Concept Gap

  1. 1

    Identify the Concept Gap

    Start by helping the student name what feels unclear. Their description keeps the conversation student-driven and helps you avoid sliding into teaching.

    You might ask

    • “What part of this feels confusing right now?”
    • “Is there a specific term or concept that feels unfamiliar?”
    • “What line of code feels the fuzziest?”

    Let the student describe the gap in their own words. Your questions help them get specific about what they need.

  2. 2

    Guide Them Back to Course Resources

    Help the student locate the concept in their course material, other course resources, or the Programming Center.

    You might ask

    • “Where in the course did you first see this concept?”
    • “Does the lab include an example or earlier practice problem that uses the same idea?”
    • “Can we find a similar example in a previous lesson?”

    Even when resources are difficult to navigate, helping the student practice finding information builds independence.

  3. 3

    Use Concept Recall

    Once the student finds the resource, invite them to explain it in their own words. If they struggle, encourage them to slow down, reread, and talk it through.

    You might ask

    • “How would you describe this concept in plain language?”
    • “What is this section saying the code should do?”
    • “What example do you see here that looks similar to your lab?”
  4. 4

    Connect the Concept Back to Their Code

    After the student reconnects with the concept, help them apply it to the code they’re working with.

    You might ask

    • “Where do you see that concept showing up in your program?”
    • “Which line is using that idea?”
    • “What do you think this part is trying to accomplish?”

    “Oh, that part is the loop” or “That line is checking the condition” shows progress, even if the code still needs work.

  5. 5

    Redirect to the Course Instructor When Needed

    If the student still needs direct instruction or clarification after reviewing the learning resources, help them prepare a question for the Course Instructor.

    “It sounds like the concept itself needs clarification. Your Course Instructor is the best person to help with that. Let’s make sure you have a really clear question to bring to them.”

    Help them prepare by asking

    • “What concept do you need clarified?”
    • “What part of the lab shows where you got stuck?”
    • “What have you already tried or tested?”
    • “What would you like the instructor to explain or confirm?”

    These details turn “I’m confused” into a specific, actionable question.

What Success Looks Like

The student can name what they do not understand, locate the relevant resource, and either reconnect with the concept or prepare a focused question for their instructor. These are meaningful coaching outcomes, even when the student needs more time or instruction to master the concept.
